# Raikas — siivousyrityksen sivumalli

Ville Rajalan tekemä suomalaisen siivousyrityksen käyttöliittymädemo.

Raikas on kuvitteellinen yritys. Sivulla ei voi tilata palveluja. Lomake näyttää ainoastaan paikallisen esimerkkivastauksen eikä lähetä tai tallenna täytettyjä tietoja.

## Julkaisu GitHub Pagesissa

1. Lisää tämän paketin tiedostot julkisen `Siivous-demo`-repositorion `main`-haaran juureen.
2. Avaa **Settings → Pages**.
3. Valitse **Deploy from a branch**, haaraksi **main** ja kansioksi **/(root)**. Tallenna.
4. Odota, kunnes GitHub näyttää julkaisun onnistuneen, ja avaa **Visit site**.

Rakennuskomentoa tai erillistä palvelinta ei tarvita. Sivusto koostuu HTML-, CSS- ja JavaScript-tiedostoista sekä kuvasta.
